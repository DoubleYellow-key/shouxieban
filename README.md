# 手写板

一个 Python 桌面窗口手写板程序，使用标准库 `tkinter` 实现，不需要浏览器。

## 功能

- 鼠标左键按住拖动即可书写
- 支持画笔、橡皮、颜色选择和笔迹粗细调整
- 支持撤销最近 50 次笔迹或清空操作
- 支持清空画布
- 支持保存文件
- 白色工具区、颜色色板和笔触预览，界面更清爽易读

## 使用

运行：

```bash
python3 app.py
```

快捷键：

- `Ctrl+Z` / `Command+Z`：撤销
- `Ctrl+S` / `Command+S`：保存

## 保存格式

程序不安装任何第三方依赖时，保存为 PostScript `.ps` 文件。

如果环境中安装了 Pillow，保存对话框会允许选择 PNG `.png`。PNG 导出依赖 Pillow 对 PostScript 的支持；如果保存失败，请改存为 `.ps`。
